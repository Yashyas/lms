Production LMS Engine • Step 01 & Step 02

Video Pipeline & Consumption Architecture

An industry-grade technical blueprint covering Garage S3 storage, presigned chunked uploads, BullMQ background transcoding, multi-bitrate HLS packaging, AES-128 encryption, secure key gating, and heartbeat progress tracking.

End-to-End System Architecture

Production Standard

This architecture mirrors platforms like Udemy and Coursera: large media uploads never bottleneck the API server, compute-heavy transcoding runs in an isolated queue, and video playback is cryptographically secured via HLS AES-128.

01. INGESTION
Direct-to-S3 Upload
Client uploads raw MP4 directly to Garage S3 via short-lived presigned PUT URLs, bypassing NestJS memory limits.
02. ORCHESTRATION
BullMQ + Redis Worker
Decoupled queue worker executes CPU-intensive FFmpeg jobs asynchronously with retry and progress reporting.
03. DRM / SECURITY
HLS AES-128 Encryptor
FFmpeg slices videos into 6-second chunks encrypted with 16-byte random keys and unique IVs for each lesson.
04. GATED STREAMING
Key Delivery Server
The player requests decryption keys from NestJS, which verifies user authentication and course enrollment via ZenStack policies.
Why AES-128 HLS Over Direct MP4 Streaming?
Plain MP4 links can be downloaded in 1-click and cannot adapt to changing student bandwidth. Multi-bitrate HLS dynamically switches resolutions (1080p, 720p, 480p, 360p) based on network speed. AES-128 encrypts every .ts segment so intercepted chunks cannot be decrypted without contacting your authorized key endpoint.

Complete Request & Processing Lifecycle

6 Stages
1
Presigned Upload Request
Instructor frontend requests an upload URL for a lesson video. NestJS validates instructor ownership and returns a signed Garage S3 PUT URL for raw-videos/{courseId}/{lessonId}/{uuid}.mp4.
2
Direct Client-to-Garage Upload
Browser streams raw MP4 directly to Garage S3 with progress bar. Once finished, client notifies NestJS POST /api/videos/upload-complete.
3
BullMQ Job Dispatch & Status Transition
NestJS updates lesson video status to PROCESSING and enqueues a job into Redis: { lessonId, rawKey, courseId }.
4
FFmpeg Transcoding, Segmenting & AES-128 Encryption
Worker pulls job, downloads raw video to temp directory, creates a 16-byte random key & IV, runs FFmpeg to generate adaptive ABR streams (1080p, 720p, 480p) + master.m3u8 + encrypted .ts chunks, and uploads them to hls/{lessonId}/ in Garage S3.
5
Secure Playback & Key Gating
Enrolled student opens lesson. The video player fetches master.m3u8. When it reaches #EXT-X-KEY:METHOD=AES-128,URI="/api/videos/:id/key", the browser requests the key. NestJS verifies enrollment via ZenStack and returns the raw 16-byte binary key.
6
Heartbeat Progress Tracking & Auto-Completion
Every 10 seconds of playback, the player pings POST /api/lessons/:id/heartbeat with current playback timestamp. When the student reaches 90% duration, the lesson is automatically marked as completed: true.

1.2 NestJS StorageModule with Presigned URLs

P0 • Backend

Create backend/src/storage/storage.service.ts using AWS SDK v3 (@aws-sdk/client-s3 and @aws-sdk/s3-request-presigner). 

import { Injectable } from '@nestjs/common';
import { S3Client, PutObjectCommand, GetObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

@Injectable()
export class StorageService {
  private readonly s3: S3Client;
  private readonly bucket: string;

  constructor() {
    this.bucket = process.env.S3_BUCKET || 'lms-media';
    this.s3 = new S3Client({
      endpoint: process.env.S3_ENDPOINT || 'http://localhost:3900',
      region: process.env.S3_REGION || 'garage',
      credentials: {
        accessKeyId: process.env.S3_ACCESS_KEY!,
        secretAccessKey: process.env.S3_SECRET_KEY!,
      },
      forcePathStyle: true, // Required for self-hosted S3 / Garage
    });
  }

  // Generate short-lived presigned URL for direct browser uploads
  async getPresignedUploadUrl(key: string, contentType: string, expiresIn = 900) {
    const command = new PutObjectCommand({
      Bucket: this.bucket,
      Key: key,
      ContentType: contentType,
    });
    return getSignedUrl(this.s3, command, { expiresIn });
  }

  // Stream video chunks or download files in background worker
  async getObjectStream(key: string) {
    const command = new GetObjectCommand({ Bucket: this.bucket, Key: key });
    const response = await this.s3.send(command);
    return response.Body as NodeJS.ReadableStream;
  }
}

1.3 BullMQ Transcoder Queue & FFmpeg HLS Worker

P0 • Processing

The worker pulls jobs from Redis, executes FFmpeg to segment videos into 6-second encrypted chunks with multi-resolution renditions, and uploads the output to Garage S3.

Multi-Bitrate ABR Ladder Specifications
Rendition Resolution Video Bitrate Audio Bitrate Ideal Network
1080p 1920 × 1080 4500 kbps 192 kbps High-speed Fiber / 5G
720p 1280 × 720 2500 kbps 128 kbps Standard Broadband / 4G
480p 854 × 480 1000 kbps 96 kbps Mobile 3G / Poor WiFi
360p 640 × 360 600 kbps 64 kbps Ultra-low Latency / Edge
FFmpeg AES-128 Encryption Command & Keyinfo Structure
# enc.keyinfo format (3 lines):
# Line 1: Decryption key URL embedded in the m3u8 playlist
# Line 2: Path to the local 16-byte raw key binary for ffmpeg to read
# Line 3: Hexadecimal initialization vector (IV)

https://api.yourlms.com/api/videos/{lessonId}/key
/tmp/jobs/{jobId}/secret.key
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855

# FFmpeg Command for HLS AES-128 Segmenting:
ffmpeg -i input.mp4 \
  -preset veryfast -g 48 -sc_threshold 0 \
  -hls_time 6 \
  -hls_playlist_type vod \
  -hls_key_info_file /tmp/jobs/{jobId}/enc.keyinfo \
  -hls_segment_filename "/tmp/output/segment_%03d.ts" \
  /tmp/output/index.m3u8

1.4 Secure AES-128 Key Delivery Endpoint

P0 • Security

When an HLS player reads #EXT-X-KEY:METHOD=AES-128,URI="...", it requests the key. The endpoint returns the raw 16-byte buffer only after verifying student enrollment or free-lesson status. 

@Controller('videos')
export class VideoKeyController {
  constructor(private readonly db: DbPoolService) {}

  @Get(':lessonId/key')
  async getKey(
    @Param('lessonId') lessonId: string,
    @Session() session: UserSession,
    @Res() res: Response
  ) {
    // 1. Fetch lesson via ZenStack policy client for current user
    const lesson = await this.db.forUser(session?.user).lesson.findUnique({
      where: { id: lessonId },
      include: { videoAsset: true }
    });

    // 2. ZenStack policy automatically throws 403 / returns null if not enrolled or not free
    if (!lesson || !lesson.videoAsset?.encryptionKey) {
      throw new ForbiddenException('You are not authorized to view this video');
    }

    // 3. Convert stored hex key to 16-byte binary buffer
    const keyBuffer = Buffer.from(lesson.videoAsset.encryptionKey, 'hex');

    // 4. Return binary buffer with strict caching headers
    res.setHeader('Content-Type', 'application/octet-stream');
    res.setHeader('Cache-Control', 'no-store, no-cache, must-revalidate, private');
    res.setHeader('Content-Length', keyBuffer.length);
    return res.end(keyBuffer);
  }
}

2.1 Heartbeat Playback Tracking Engine

P0 • Consumption

While a student watches a lesson, the frontend player emits a throttled heartbeat ping every 10 seconds. This updates their last played position and automatically triggers completion once the progress threshold is reached. 

// POST /api/lessons/:id/heartbeat
// Request Body: { currentSeconds: 145, durationSeconds: 600 }

@Injectable()
export class ProgressService {
  constructor(private readonly db: DbPoolService) {}

  async recordHeartbeat(lessonId: string, currentSeconds: number, durationSeconds: number, user: AuthUser) {
    const COMPLETION_THRESHOLD = 0.90; // 90% watched marks as completed
    const shouldMarkCompleted = (currentSeconds / durationSeconds) >= COMPLETION_THRESHOLD;

    return await this.db.forUser(user).lessonProgress.upsert({
      where: {
        userId_lessonId: { userId: user.id, lessonId }
      },
      create: {
        userId: user.id,
        lessonId,
        lastPlayedSeconds: Math.floor(currentSeconds),
        durationSeconds: Math.floor(durationSeconds),
        completed: shouldMarkCompleted,
        completedAt: shouldMarkCompleted ? new Date() : null,
      },
      update: {
        lastPlayedSeconds: Math.floor(currentSeconds),
        durationSeconds: Math.floor(durationSeconds),
        // Once marked completed, keep it completed
        ...(shouldMarkCompleted ? { completed: true, completedAt: new Date() } : {})
      }
    });
  }
}

2.2 Course Completion & Progress Aggregation

P1 • Analytics

Calculate overall course completion percentage, total lessons watched, and identify the next unwatched lesson for a seamless "Continue Learning" UX. 

// GET /api/courses/:courseId/progress
@Get(':courseId/progress')
async getCourseProgress(@Param('courseId') courseId: string, @Session() session: UserSession) {
  const user = session.user;

  // 1. Fetch total lessons in course
  const lessons = await this.db.forUser(user).lesson.findMany({
    where: { courseId },
    orderBy: { position: 'asc' },
    select: { id: true, title: true, position: true }
  });

  // 2. Fetch completed lesson IDs for this user
  const progressRecords = await this.db.forUser(user).lessonProgress.findMany({
    where: {
      lessonId: { in: lessons.map(l => l.id) },
      completed: true
    },
    select: { lessonId: true }
  });

  const completedSet = new Set(progressRecords.map(p => p.lessonId));
  const total = lessons.length;
  const completed = progressRecords.length;
  const percentage = total > 0 ? Math.round((completed / total) * 100) : 0;

  // 3. Find first unwatched lesson
  const nextLesson = lessons.find(l => !completedSet.has(l.id)) || lessons[0];

  return {
    totalLessons: total,
    completedLessons: completed,
    percentage,
    isCourseCompleted: percentage === 100,
    nextLessonId: nextLesson?.id ?? null
  };
}

2.3 Frontend Player Setup (Hls.js + Token Auth)

P0 • Frontend

Next.js integration snippet using hls.js. It intercepts AES-128 key requests to attach the session cookie/Bearer token and sends 10-second heartbeats. 

import Hls from 'hls.js';
import { useEffect, useRef } from 'react';

export function LessonVideoPlayer({ masterPlaylistUrl, lessonId, initialTime = 0 }) {
  const videoRef = useRef<HTMLVideoElement>(null);

  useEffect(() => {
    const video = videoRef.current;
    if (!video) return;

    if (Hls.isSupported()) {
      const hls = new Hls({
        // Attach credentials/cookies so the key request can be authorized
        xhrSetup: (xhr, url) => {
          xhr.withCredentials = true; 
        }
      });

      hls.loadSource(masterPlaylistUrl);
      hls.attachMedia(video);

      hls.on(Hls.Events.MANIFEST_PARSED, () => {
        // Resume playback from last saved timestamp
        if (initialTime > 0) video.currentTime = initialTime;
      });

      // Heartbeat every 10 seconds
      let lastPing = 0;
      const onTimeUpdate = () => {
        const now = Math.floor(video.currentTime);
        if (now - lastPing >= 10 && video.duration) {
          lastPing = now;
          fetch(`/api/lessons/${lessonId}/heartbeat`, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ currentSeconds: now, durationSeconds: Math.floor(video.duration) })
          });
        }
      };

      video.addEventListener('timeupdate', onTimeUpdate);
      return () => {
        video.removeEventListener('timeupdate', onTimeUpdate);
        hls.destroy();
      };
    }
  }, [masterPlaylistUrl, lessonId, initialTime]);

  return <video ref={videoRef} controls className="w-full rounded-lg bg-black aspect-video" />;
}

ZMODEL

Add the dedicated VideoAsset and LessonProgress models with declarative ZenStack access policies. 

// 1. Update User model to include lesson progress relation
model User {
    // ... existing fields ...
    lessonProgress LessonProgress[]
}

// 2. Video processing states
enum VideoStatus {
    PENDING_UPLOAD
    PROCESSING
    READY
    FAILED
}

// 3. Dedicated VideoAsset Model
model VideoAsset {
    id              String       @id @default(cuid())
    lessonId        String       @unique
    lesson          Lesson       @relation(fields: [lessonId], references: [id], onDelete: Cascade)
    status          VideoStatus  @default(PENDING_UPLOAD)
    rawStorageKey   String?
    hlsMasterUrl    String?
    durationSeconds Int          @default(0)
    encryptionKey   String?      // 16-byte AES key in hex (backend-only)
    encryptionIv    String?      // 16-byte IV in hex
    errorMessage    String?
    createdAt       DateTime     @default(now())
    updatedAt       DateTime     @updatedAt

    // Encryption key is readable by admin or internal worker
    @@allow('all', auth().role == 'admin' || lesson.course.instructorId == auth().id)
    @@map('video_asset')
}

// 4. Update Lesson model
model Lesson {
    // ... existing fields ...
    videoAsset      VideoAsset?
    progress        LessonProgress[]
}

// 5. LessonProgress Model (Student tracking)
model LessonProgress {
    id                String    @id @default(cuid())
    userId            String    @default(auth().id)
    user              User      @relation(fields: [userId], references: [id], onDelete: Cascade)
    lessonId          String
    lesson            Lesson    @relation(fields: [lessonId], references: [id], onDelete: Cascade)
    lastPlayedSeconds Int       @default(0)
    durationSeconds   Int       @default(0)
    completed         Boolean   @default(false)
    completedAt       DateTime?
    updatedAt         DateTime  @updatedAt

    @@unique([userId, lessonId])
    @@allow('read,create,update', auth().id == userId || auth().role == 'admin')
    @@allow('read', lesson.course.instructorId == auth().id)
    @@map('lesson_progress')
}
