Payment Engineering Spec

LMS Stripe Integration Architecture

Two-stage roadmap: Stage 1 delivers zero-friction local testing via Client Redirect Verification; Stage 2 provides production hardening via Webhooks.

Stage 1 Execution Flow (Zero External Tooling)

Client Redirect Verification

This local architecture requires zero CLI daemons, no Ngrok tunnels, and no raw-body signature verification. Everything runs over standard authenticated REST requests.

01
Student clicks "Buy Course ($49)"
Frontend calls POST /payments/checkout/:courseId with the student's session token.
02
Backend initiates Stripe Checkout Session
Validates course is published, price > 0, and user isn't already enrolled. Creates a Payment record in Postgres with status: 'pending'. Calls Stripe API and returns checkoutUrl.
03
Hosted Stripe Checkout & Test Payment
Student is redirected to Stripe's secure page. They type test card 4242 4242 4242 4242 and complete checkout.
04
Stripe Redirects Back to Next.js Frontend
Browser lands on http://localhost:3001/courses/:id?success=true&session_id=cs_test_....
05
Immediate Verification & Instant Enrollment
Frontend calls POST /payments/verify-session { sessionId }. Backend checks with Stripe: session.payment_status === 'paid'. In an atomic transaction, it updates the Payment to completed and creates the Enrollment record!

4. Controller: payments.controller.ts

import { Controller, Post, Param, Body } from '@nestjs/common';
import { PaymentsService } from './payments.service.js';
import { VerifySessionDto } from './dto/verify-session.dto.js';
import { Session, type UserSession } from '@thallesp/nestjs-better-auth';

@Controller('payments')
export class PaymentsController {
  constructor(private readonly paymentsService: PaymentsService) {}

  // 1. Create Checkout Session
  @Post('checkout/:courseId')
  createCheckout(
    @Param('courseId') courseId: string,
    @Session() session: UserSession,
  ) {
    return this.paymentsService.createCheckoutSession(courseId, session.user);
  }

  // 2. Client Redirect Verification (Works locally with zero CLI)
  @Post('verify-session')
  verifySession(
    @Body() dto: VerifySessionDto,
    @Session() session: UserSession,
  ) {
    return this.paymentsService.verifySession(dto.sessionId, session.user);
  }
}

Stage 2: Production Hardening (Webhooks)

Future Production

When preparing to go live, keep Stage 1 and attach the Webhook listener as an asynchronous safety net to handle closed tabs, network drops, and automated refunds.

Webhook Controller Endpoint

@Post('webhook')
@AllowAnonymous()
async handleWebhook(
  @Headers('stripe-signature') signature: string,
  @Req() req: RawBodyRequest<Request>,
) {
  const event = this.stripe.webhooks.constructEvent(
    req.rawBody!, // Requires raw unparsed Buffer
    signature,
    this.config.get('STRIPE_WEBHOOK_SECRET')!,
  );

  if (event.type === 'checkout.session.completed') {
    await this.paymentsService.fulfillOrder(event.data.object);
  }

  if (event.type === 'charge.refunded') {
    await this.paymentsService.revokeEnrollment(event.data.object);
  }

  return { received: true };
}

schema.zmodel Definition

ZenStack ORM

Add this model to packages/db/zenstack/schema.zmodel right after Enrollment: 

model Payment {
    id                    String      @id @default(cuid())
    
    // Relations
    userId                String      @default(auth().id)
    user                  User        @relation(fields: [userId], references: [id], onDelete: Cascade)
    
    courseId              String
    course                Course      @relation(fields: [courseId], references: [id], onDelete: Cascade)
    
    enrollmentId          String?     @unique
    enrollment            Enrollment? @relation(fields: [enrollmentId], references: [id], onDelete: SetNull)

    // Financials
    amount                Int         // stored in cents/paise
    currency              String      @default("usd")
    status                String      @default("pending") // 'pending' | 'completed' | 'failed'
    
    // Stripe data
    provider              String      @default("stripe")
    stripeSessionId       String?     @unique
    stripePaymentIntentId String?     @unique
    
    createdAt             DateTime    @default(now())
    updatedAt             DateTime    @updatedAt

    // ZenStack Policies
    @@allow('read', auth().id == userId || course.instructorId == auth().id || auth().role == 'admin')
    @@allow('create', auth().id == userId || auth().role == 'admin')
    @@allow('update', auth().id == userId || auth().role == 'admin')

    @@map('payment')
}
